## 一、当前状态分析

### 1.1 已有优势

| 方面 | 现状 | 评价 |
|------|------|------|
| **多视角生成** | 4 个视角（供应链、安全合规、临床护理、适老化改造） | ✅ 优秀 |
| **防同质化引擎** | 每次随机绑定 1 个子视角 | ✅ 优秀 |
| **GEO 优化** | 有专门的 GEO 提示词（字数、结构、引用格式） | ✅ 良好 |
| **B2B 专业语气** | 严格的红线约束，禁止 C 端话术 | ✅ 优秀 |
| **中文输出** | 强制全中文，英文缩写替换规则 | ✅ 优秀 |
| **任务调度** | 11 个活跃任务，3 个目标站点 | ✅ 良好 |
| **分发系统** | 自动同步到远程站点 | ✅ 良好 |

### 1.2 缺失部分

| 方面 | 现状 | 缺失 | 影响 | 优先级 |
|------|------|------|------|--------|
| **标题优化** | 有基础标题生成 | 缺乏 GEO 标题评分、意图分析 | 标题可能不被 AI 搜索引用 | P0 |
| **内容质量评估** | 无 | 缺乏生成后质量检查 | 低质量文章可能被发布 | P0 |
| **品牌知识库** | 无 | 缺乏产品参数、认证信息 | 文章缺乏权威性 | P1 |
| **效果监测** | 无 | 缺乏 AI 搜索引用追踪 | 无法知道哪些内容有效 | P1 |
| **内容迭代** | 无 | 缺乏基于效果的内容优化 | 无法持续改进 | P2 |
| **A/B 测试** | 无 | 缺乏新旧提示词对比 | 无法验证改进效果 | P1 |
| **回滚机制** | 无 | 缺乏快速回滚能力 | 新提示词出问题无法快速恢复 | P1 |
| **监控面板** | 无 | 缺乏可视化效果展示 | 无法直观看到改进效果 | P2 |

## 二、完善后的方案

### 2.1 阶段 1：内容质量提升（第 1-3 天）

#### 任务 1.1：集成 GEO 标题优化技能

**目标**：提升标题被 AI 搜索引用的概率

**来源**：
- `yao-geo-skills/docs/skills/yao-geo-title-optimizer.md`
- `yao-open-prompts/prompts/08-ai-marketing/geo-article-generator.md`

**具体步骤**：
```bash
# 1. 读取标题优化技能
cat ~/yao-geo-skills/docs/skills/yao-geo-title-optimizer.md

# 2. 提取核心方法论
# - GEO 标题评分维度
# - 意图分析框架
# - 实体映射规则

# 3. 更新 GEOFlow 的标题生成提示词
# 文件：prompts 表，id=1（默认标题生成）、id=7（监控塔标题生成）
```

**验收标准**：
- [ ] 新提示词包含 GEO 标题评分维度
- [ ] 新提示词包含意图分析框架
- [ ] 新提示词包含实体映射规则
- [ ] 测试生成 5 个标题，质量优于旧提示词

**风险**：
- 风险：新提示词可能生成不符合 B2B 语气的标题
- 应对：保留旧提示词作为备份，可快速回滚

**回滚方案**：
```sql
-- 如果新提示词效果不好，回滚到旧版本
UPDATE prompts SET content = '<旧内容>' WHERE id = 1;
```

```bash
  "SELECT id, name, type FROM prompts ORDER BY id;"

# 更新提示词
docker exec geo-system-postgres psql -U geo_user -d geo_system -c \
  "UPDATE prompts SET content = '<新内容>' WHERE id = <提示词ID>;"

# 查看任务使用的提示词
docker exec geo-system-postgres psql -U geo_user -d geo_system -c \
  "SELECT t.id, t.name, p.name as prompt_name FROM tasks t LEFT JOIN prompts p ON t.prompt_id = p.id WHERE t.status = 'active';"
```

```sql
UPDATE prompts SET content = '<旧内容>' WHERE id = <提示词ID>;
```
