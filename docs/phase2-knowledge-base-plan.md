# 阶段 2：品牌知识库建设详细规划

> **时间范围**: 第 4-14 天（共 11 天）
> **目标**: 为护理床和监控塔建立结构化品牌知识库
> **产出**: 知识图谱、事实卡、FAQ、禁止用语、提示词输入包

---

## 一、阶段目标

### 1.1 核心目标

| 目标 | 说明 | 成功标准 |
|------|------|----------|
| 建立品牌知识图谱 | 护理床、监控塔的实体和关系 | 覆盖 ≥ 50 个实体 |
| 建立事实卡库 | 产品参数、认证、案例 | 覆盖 ≥ 100 个事实卡 |
| 建立 FAQ 库 | 高频问题和标准答案 | 覆盖 ≥ 30 个 FAQ |
| 建立禁止用语清单 | AI 回答禁止使用的表达 | 覆盖 ≥ 20 条 |
| 导入 GEOFlow 知识库 | 可被文章生成调用 | 查询成功率 ≥ 95% |

### 1.2 预期效果

| 方面 | 当前 | 预期 |
|------|------|------|
| 文章权威性 | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 数据准确性 | 编造风险高 | 基于知识库，准确率 ≥ 95% |
| 内容一致性 | 各文章不统一 | 统一品牌口径 |
| AI 引用率 | 未知 | 预期提升 30%+ |

#### 2.1.4 建立知识图谱（第 7-8 天）

**目标**：将收集的信息整理成结构化知识图谱

**实体类型**：

| 实体类型 | 说明 | 示例 |
|----------|------|------|
| 品牌 | 公司/品牌信息 | 程恩医疗器械、铁塔厂 |
| 产品 | 产品型号和参数 | 电动护理床、四角监控塔 |
| 服务 | 产品相关的服务 | 安装、培训、维保 |
| 功能 | 产品功能特性 | 升降、翻身、起背 |
| 技术 | 技术参数和标准 | 材质、承重、抗风等级 |
| 认证 | 认证和资质 | 国标、CE、FDA |
| 场景 | 应用场景 | 养老院、医院、林业 |
| 客户 | 客户类型和案例 | 养老机构、政府部门 |
| 案例 | 具体案例 | XX养老院采购案例 |
| 价格 | 价格信息 | 价格区间、价格构成 |

**关系类型**：

| 关系类型 | 说明 | 示例 |
|----------|------|------|
| 制造 | 品牌制造产品 | 程恩 → 制造 → 护理床 |
| 包含 | 产品包含功能 | 护理床 → 包含 → 升降功能 |
| 适用 | 产品适用场景 | 护理床 → 适用 → 养老院 |
| 认证 | 产品获得认证 | 护理床 → 认证 → 国标 |
| 服务 | 品牌提供服务 | 程恩 → 提供 → 安装服务 |
| 案例 | 客户使用产品 | XX养老院 → 使用 → 护理床 |

**产出**：
- [ ] 实体清单（JSON 格式）
- [ ] 关系清单（JSON 格式）
- [ ] 知识图谱可视化（Mermaid）
- [ ] JSON-LD 格式
- [ ] RDF 三元组

**验收标准**：
- 实体覆盖 ≥ 50 个
- 关系覆盖 ≥ 100 条
- 每个实体有证据来源
- 每个关系有证据 ID
